# Libraries bundled in the AppImage

The AppImage carries the desktop libraries the app needs at run time (GTK 3, WebKitGTK and their
dependencies), copied from the system that builds it. Cawget's own code and the components listed in
THIRD_PARTY_LICENSES.md are compiled into the `cawget` binary; the libraries below are separate shared
libraries inside the AppImage, each under its own licence. The .deb and .rpm packages bundle none of
them: they use the distribution's libraries.

This list comes from a reference build (107 source packages, 191 shared libraries). Release builds run on
Ubuntu 22.04 and bundle that release's versions of the same projects; every GitHub release has an exact list
attached (`bundled-libraries.txt`, generated by the release workflow from the Debian package database).

All licences are compatible with distributing the AppImage under GPL-3.0-or-later. Where a project offers a
choice ("OR"), the compatible option applies. libayatana-appindicator is GPL-3.0-only, which is compatible
with GPL-3.0-or-later as distributed (the combined work is then distributed under GPLv3).

## Source code of the LGPL and GPL libraries

distribution that built them: for release builds, the Ubuntu 22.04 source packages (`apt-get source <package>`
or https://launchpad.net/ubuntu/+source/<package>), and from each project's upstream site listed below. The
release notes of each AppImage say how its corresponding source is provided.
